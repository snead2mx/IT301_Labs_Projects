This article will focus on how I used a Linux specific CD ripping program to rip CD's of mine since I started getting into the habit of doing that when I first switched an old laptop to a Linux distribution. As this laptop was both the only one I actively used that had a CD drive, and I have only heard of Windows ripping options such as Windows Media Player and Exact Audio Copy, searching for a new program to use was something.

For Linux, there are both dedicated graphic applications, and applications that ran within a terminal, which is not surprising with how Linux works. For a CD application, I did look for something that made it easy to choose audio formats and use a template for naming files. I also wanted a program that could deal with possible CD reading errors since I had heard that Exact Audio Copy dealt with that.

I settled with Asunder.
