What did I want?

I did not want to have players with as minimum features as possible. I felt that being limited to just having a player and a few playlist options were not enough. Although I had a small library when I started looking for players, being able to search and queue songs in specific ways such as at the end of a queue or right afterwards a certain song were invaluable to me.

Right off the bat, I was recommended a program that gave me everything I wanted in a music player. The problem was that it was Windows only, and even with the WINE tool, it was not entirely functional. Most of the programs listed below have a common availability on Linux because I was looking for programs similar in function and appearance to my preferred Windows program, so that I can have a fully functional Linux music player to use when I don't feel like using WINE.

Programs I had tried

MusicBee Windows

This had what I had hypothetically wanted with a local music player, with many customization and data tagging features. It is very easy to change information of groups of songs or albums by Control clicking tracks in your library and changing fields like artists and albums. You can also convert audio types, possibly rip CD's, syncing music to a phone, etc./p>

This program's queuing system is what I've liked the most out of all the music programs here. There is a dedicated next context menu that allows me to stack a bunch of queued tracks to play next, without it getting scrambled. There is also a queue last option, so if I want to add more songs at the end of the playlist, it remains at the end.

Most customization is built into the player, with draggable panels and dropdown menus that can hide certain features from the user interface. There are a lot of themes you can switch into, and those themes will instantly take effect. It can change button and panel appearance. The theme used in the image is Midnight.

Even with its amount of features, you can get more features and themes into the player using community add-ons.

This program is Windows only, so I had to once again use WINE to run it. In order to have it run, you have to load these components within WINE: cjkfonts, dotnet48, xmllite, and gdiplus.

You'd also need to find a Bass_aac.dll file so that certain file types could load, and lib32-gnutls for some internet connections to work smoothly. This component will vary by operating system.

Unfortunately some features I use daily such as syncing needs further configuration from WINE I had not figured out yet. For the syncing example, WINE on its own cannot detect plugged in devices such as phones and CD drives. Performance is also not the best.

Strawberry Linux

Strawberry is likely the closest I've gotten to the features in a native Linux program I've wanted. The user interface is less customizable though. Queuing songs depends on clicking groups of songs in a single panel library which is very nice to use for me.

If I tried to do something similar in MusicBee, it would have me just play the song I selected instead. Even if there are no features related to CD ripping, the program makes up for with a lot of built in connections such as radios, logins to streaming services like Spotify and Tidal, and even logins to virtual library servers. I've been trying to also set up a virtual library recently, so I might find more use of this feature in the future.

Do note that you'd need a subscription to use this app outside of Linux environments.

VLC Media Player Both

This will not have its own photo because of how widely used the program is.

It is actually possible to play a music library in VLC, but I unfortunately ran into some pet peeves: shuffling is really weird. When playing all music in my Music folder, it appears to only queue a few certain folders, which is really bad if you have a big library with many subfolders. Apparently the main solution is to select all contents of each folder and create your own library file out of it. Based on the size of my library and how each track is nested in an artist and then album subfolder, this would unfortunately take a while.

Either way, I prefer using this player to open files on their own, not to play multiple songs in a queue. Some takeaways about this program as a library organizer though, is that you can still rip contents of a CD or DVD, and there are some connection based options to open files outside of the library if needed such as network stream. This also has the least amount of metadata editing features.
